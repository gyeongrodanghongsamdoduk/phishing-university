# 피싱대학 · 피싱 구별 퀴즈

정보과학의 날 체험 부스용 정적 웹사이트입니다. 별도의 서버나 데이터베이스가 필요하지 않습니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 바로 실행됩니다.

퀴즈 순서:
1. 기초 판단 2문제 — `피싱 의심 / 정상 안내` 중 선택 + 핵심 근거 1개
2. 사이트 화면 비교 5문제 — 왼쪽/오른쪽 중 피싱 화면 선택
3. 대처 방법 퀴즈
4. 결과 화면

사이트 비교 이미지는 클릭하면 전체 화면으로 확대됩니다.

## GitHub Pages로 호스팅하기 (권장)

이 프로젝트는 GPT 호스팅보다 **GitHub Pages**에 올려 운영하는 것을 권장합니다.

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 `index.html`, `style.css`, `app.js`, `investigation.js`, `assets` 폴더를 그대로 업로드합니다.
3. Repository의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 표시되는 `https://사용자이름.github.io/저장소이름/` 주소로 접속합니다.

모든 경로가 상대경로로 되어 있어 GitHub Pages에서 별도 수정 없이 작동합니다.

## 운영 시 주의

- 모든 비교 화면은 교육용 예시입니다.
- 실제 피싱 여부는 화면 디자인 하나만으로 확정하지 말고, 정확한 도메인·공식 앱·공식 고객센터 등 독립적인 경로로 확인하는 습관을 강조해 주세요.
- 실제 개인정보를 입력하는 기능과 서버 전송 기능은 없습니다.
